# 多格漫画批量生成流程（2026-08 验证，15 格拼版）

作者要「一组漫画/多格剧情色图」时的标准流程：队列批量提交 → 批量轮询 → 拷贝改名 → Pillow 拼版嵌字 → 交付一张总图。

## 步骤

1. **剧情分幕**：15 格按 4 幕递进（调戏→反转→侵犯→收尾），每格 1-2 句提示词（六层结构，角色串常驻，`(nsfw:1.4)` 定调）。逐格设计对白嵌字（BA 味：称呼 sensei）。
2. **队列提交**：逐张设 [23] 提示词 → graphToPrompt → fetch `/api/prompt`，收集 15 个 prompt_id（每次调用换 `window.__nX` 变量名，console 全局作用域）。`node_errors` 全空即全部入队。
3. **批量轮询**（后台 python）：轮询全部 id，success 后记录 `subfolder/filename`，error 打印节点信息，15 个全完成即退出（间隔 15s，上限 600 轮）。
4. **拷贝改名**：F 盘 output 按格序拷为 `p01.png`…`p15.png`（D 盘 tmp）。拼版脚本按 pNN 读取。
5. **Pillow 拼版**：`scripts/manga_panel.py`（3 列 × 5 行网格、金色描边、每格底部半透明对白条、顶部大标题、底部署名）。输出 JPG（q92，~2.7MB）优于 PNG（大图 30MB+）。
6. **交付**：MEDIA 总图 + 分幕表格（格号/画面/对白）。

## 嵌字风格（作者验收通过）

- 日式拟声词：パサッ（掀开）／じゅわ（湿润）／ぴくんっ（颤抖）——倾斜大字号 + 黑描边
- 对白气泡：白底黑框圆角 + 尾巴三角，叠图角落，指向画面焦点
- 标题：「放学后の办公室 · 橘望的十五连」式（日文主标 + 中文副标 + R-18 刊头）
- 署名：制作人：作者 · 出品

## Pitfalls

- 15 张单图交付 = 麻烦；作者要的是「一组漫画」，交付拼版总图，单图副本留 D 盘备查
- 批量提交中途浏览器会话可能重置（app not defined）——重新导航 + 重载工作流，已入队的 prompt 不受影响
- 拼版脚本 `DIALOG` 数组按格序排列，换剧情只需改数组
