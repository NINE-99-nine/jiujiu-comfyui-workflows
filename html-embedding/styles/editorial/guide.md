# 社论风 · Editorial（风格指导）

## 是什么

杂志/书刊封面式的现代排版（凯特琳参考海报、赛琳娜角色海报同源）——**衬线大字标题、左文右图、统一底色、巨大留白、细线分隔、短句格言**。冷静、克制、高级，适合角色海报/系列封面/讲究气质的版面。

## 触发词

「社论风」「杂志风」「凯特琳式」「左文右图」「衬线海报」「有气质的封面」、以及需要**高级、冷静、版式感**的角色海报/封面。

## ★ 图层关系铁律（最高优先）

用户的正确图层顺序（由下到上）：
```
① 统一底色层（最底）—— 米白 #FAF9F8 铺满全画布 = "扩展画布"
② 人物 + 文字（并列，都叠在底色上）—— 人物图是底色上的独立图层，文字是另一块
③ 文字（可置最上，但置于底色左侧空白区，不压人物）
```

**禁止的做法**（作者明确批评过）：
- ❌ 把文字区做成**不透明色块面板**（z-index 高于人物）盖在图上 → 人物延伸到该区域的部分被挡住
- ❌ 简单地"左色块 + 右人物"**左右并列分栏**，若人物延伸进色块区会被挡
- ❌ 半透明 wash 压制在原图上冒充"扩展"

**正确做法**：底色是**画布 background**（最底），人物与文字都是叠在底色上的**独立元素**（并列不互相遮挡）。人物左侧轮廓完整，人物右侧**自然被画布边缘裁切**（非被色块挡）。

## 核心要素

| 要素 | 达成 |
|---|---|
| **衬线大字标题** | `Georgia`/宋体衬线，`scaleY(1.16)` 拉长，`letter-spacing .16em`，`SERENA` 式 |
| **穿字细横线** | 标题 `::after` 水平线在字后（`z-index:0`），在字母空隙露头 |
| **短句格言** | 全大写衬线短句断行，`— SHE REMEMBERS ALL.` 破折号副句 |
| **左文右图** | 文字区 44%（底色上），人物区 56%（底色上，右置） |
| **统一底色 + 无缝过渡** | 全画布 `#FAF9F8`；人物左缘 `linear-gradient` 淡入、裙摆下沿渐隐、底座柔和投影 |
| **细线分隔** | `border-top`/`border-bottom` 淡线（`#ddd9cf`） |
| **纸张质感** | SVG `feTurbulence` 噪点 + `mix-blend-mode:multiply` 亚光 |

## 配色 Token

```
--bg:      #FAF9F8   /* 米白衣底（采样原图背景） */
--ink:     #24242c   /* 深墨文字 */
--ink-2:   #45454e   /* 副文字 */
--line:    #ddd9cf   /* 细线分隔 */
--accent:  #a11226   /* 血红点缀（角色瞳色/蝴蝶结呼应） */
```

## 达成要点（CSS）

```css
.stage { position:relative; background:#FAF9F8; }              /* ① 底色层（扩展画布） */
.figure { position:absolute; right:0; width:60%; z-index:1;     /* ② 人物：底色上，右置 */
  background-image:url(...); background-size:cover; background-position:26% 30%; }
.text { position:absolute; left:0; width:44%; z-index:5; }      /* ③ 文字：底色上，左侧 */
.title { font-family:Georgia,serif; transform:scaleY(1.16); letter-spacing:.16em; }
.title-block::after { content:""; top:52%; /* 穿字线 */ z-index:0; }
```

## 注意 / 踩坑（赛琳娜三版迭代结论）

1. **先看底图留白结构**再决定排布（顶部紧凑/底部充足/两侧被辫子占）——别默认往一侧塞。
2. **人物左侧轮廓（脸/肩）必须完整**；人物右侧用**画布边缘自然裁切**（自然、有张力），不是被色块挡。
3. **过渡要柔和**：人物左缘横向渐变淡入底色、裙摆下沿纵向渐隐、底座椭圆投影（消除"裁切生硬"和"人物漂浮"）。
4. **文字放底色空白区**，不与人物/辫子打架；辫子伸入文字区时，把文字区右边界让出或用留白避让。
5. **文字层级 ≤ 3 级**（主标题 / 副标 / 短句），避免标签堆砌。
6. **用 vision 检查**：图层顺序（人物是否被挡）、人物完整性、过渡是否无缝、文字是否压主体——逐项过再交付。
7. **采样底色**：读原图四角像素取背景色（赛琳娜 `#FAF9F8`），保证扩展区与图无缝。

## 案例

- **赛琳娜 · 衬线角色海报**（`case.html`）—— 人物右置左缘完整、右缘画布裁切、左文右图、米白底血红点缀。底图走 `workflows/anima` 生成立绘。

## 标准流程

1. ComfyUI 出立绘（anima；白底干净背景、人物侧半身或立姿）
2. 读底色 → HTML 分层（底色→人物并列→文字）→ 截图
3. vision 逐项检查图层/完整性/过渡 → 交付中文名成品
