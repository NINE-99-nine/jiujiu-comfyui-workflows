# 骇客终端风

黑底荧光绿 CRT 终端。作者选定用于「扬」人设图（2026-08-09）。

## 达成要点

- 色板：黑底 `#040a06`、荧光绿 `#39ff6a`/`#00ff5f`、暗绿 `#2f9e52`/`#1f7a3d`、警示红 `#ff5f3a`（少量）
- 字体：Consolas 等宽
- 扫描线：`repeating-linear-gradient(0deg, rgba(0,0,0,.28) 0 1px, transparent 1px 3px)`
- 暗角：radial-gradient；闪烁光标：blink 动画
- 属性条：div 宽度条（键值对走 flex，**不走字符对齐**——中英文等宽对齐会乱）
- 真实质感：真实终端窗口逻辑（标题栏 -□×、命令行、文件路径、状态栏）、克制的辉光（text-shadow 小半径）、统一间距节奏、box-drawing 边框精准

## 注意点

- **禁止贴标签堆元素、禁止大杂烩**（作者原话：「你的 html 审美还是有待提高」）
- 大字覆盖是「文字不遮主体」唯一例外：覆盖在图片边缘 + 黑底荧光绿强对比 + 主体完整可见
