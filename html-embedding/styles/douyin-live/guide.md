# 场景拟真式（抖音直播 UI / 平台仿生）

文字"长在画面里"，模拟真实平台 UI。案例：赛琳娜·白殿漫游直播界面（2026-08-02）。

## 版式骨架（1200×1800 竖屏）

```
body 1200×1800, overflow:hidden, 黑色背景
├─ .stage 绝对定位铺满：img 底图 + .shade 渐变遮罩（顶部 .35→0 / 底部 .55→0 / 左侧 .35→0）
├─ .topbar 顶部直播栏（top:36px）：直播徽章 + 主播卡 + 关注按钮
├─ .title-banner 标题横幅（top:130px）：旋转 -1.5° 白色大字卡 + 副题条
├─ .hot-badge 人气角标（右上）：「🔥 人气巅峰 · 全站 TOP3」旋转 3° 红章
├─ .hearts 飘浮爱心（右侧，CSS 动画 floatUp 3s infinite）
├─ .side-actions 右侧互动列：👍💬⭐🎁 圆形图标 + 数字
├─ .danmaku 弹幕区（左下）：4 条圆角胶囊，slideIn 动画错峰
└─ .shopping 底部小黄车：购物袋图标 + 商品名 + 限量/已抢 + 立即抢购按钮
```

## 关键 CSS

- 直播徽章：`rgba(0,0,0,.5)` + `backdrop-filter:blur(8px)` 毛玻璃胶囊；红点 `pulse 1.2s infinite`
- 弹幕：`rgba(0,0,0,.45)` 胶囊，`slideIn` 四条 animation-delay 0.2/0.9/1.6/2.3s 错峰；VIP 👑 前缀粉色字
- 小黄车：`linear-gradient(135deg, rgba(20,14,30,.92), rgba(40,20,40,.92))` 圆角 22px，金边 `rgba(255,215,94,.5)`，「立即抢购」红橙渐变按钮

## 嵌字铁律（画面文字互相印证）

- 弹幕/文案贴画面内容：角色仪态→弹幕夸；角色配饰→小黄车卖同款（限量 500 已抢 437）
- 直播数据虚构但要合理（观看 128.4万/粉丝 320.6万）
- 可仿生平台：B站/YouTube（进度条/三连/弹幕）、视频封面（大字标题+角标徽章）、商品图（价格标签/优惠券/已售件数）

## Pitfalls

- 遮罩 .shade 必须存在，否则白字在亮背景不可读
- 弹幕/小黄车/互动列宽度别超画布 1/3，避免盖主体（人物在右则 UI 靠左）
- 动画不影响 headless 截图（取起始帧）；爱心若需显示须设初始 opacity:1
