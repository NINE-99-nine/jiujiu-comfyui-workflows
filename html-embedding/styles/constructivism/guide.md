# 构成主义 · Constructivism（风格指导）

## 是什么

苏联先锋派（Rodchenko / 李西茨基）海报语言的现代化演绎——**几何切割 + 大字排版 + 强对比 + 对角线动感**。在作者体系里默认与**魔幻/有机**混合：硬几何骨架 × 柔和有机曲线 × 魔幻底图，做「魔幻构成主义」混合风（非纯构成做减法）。

## 触发词

「构成主义」「苏联海报」「几何海报」「先锋派」「《表里之介》风」、以及需要**强烈、史诗、有宣言感**的海报时。

## 核心要素

| 要素 | 达成 | 说明 |
|---|---|---|
| **几何色块参与切割** | 红三角 `border`、红圆 `border-radius`、斜带 `rotate(-16deg)` | 几何必须**切割/重构画面**，不是贴片装饰 —— 最关键的构成主义判断 |
| **巨型倾斜标题** | `transform: rotate(-6deg)`，粗黑 900，扁平 | 视觉主体；可叠色块咬合（`::after` 红色 multiply 衬底） |
| **对角线/放射线** | `repeating-conic-gradient` 射线、贯穿斜带 | 动感 + 射线网格（转轮感） |
| **强对比配色** | 红/黑/米白 + 主题色 | 构成主义经典三色 + 魔幻/有机点缀色 |
| **符号** | 圆环（结界/界门）、十字格线、规尺线 | 点题「表/里交界」等概念 |
| **有机层** | SVG 贝塞尔金线（`<path>` 流线） | 让硬几何「活」起来（作者要的「生动」） |

## 达成要点（CSS 手法）

```css
/* 三角切割左上 */
.geo-tri { border-top: 300px solid var(--red); border-right: 430px solid transparent; }
/* 大圆压右下（对角平衡） */
.geo-disc { border-radius: 50%; }
/* 贯穿斜带（rotate 与标题斜角呼应） */
.geo-band { transform: rotate(-16deg); }
/* 放射线（太阳中心） */
.rays { background: repeating-conic-gradient(from 176deg at 50% 32%, rgba(232,194,101,.15) 0deg 3deg, transparent 3deg 13deg); }
/* 扁平标题（非 glossy 3D） */
.title-main { font-weight: 900; text-shadow: 0 3px 0 rgba(0,0,0,.35); }
```

## 注意 / 踩坑（《表里之介》三版迭代结论）

1. **几何要结构连贯** —— 三角、斜带、圆沿同一条对角线方向「生长」，避免各自为政的孤立色块。
2. **斜带避开标题字主体** —— 从标题上方扫过、或留间隙穿过；穿字会伤可读性。
3. **文字层级 ≤ 3 级** —— 主标题 / 英文副标 / 故事句；多余的标签合并或删。
4. **对角线平衡** —— 左上红三角 ↔ 右下红圆呼应；避免左重右轻。
5. **文案对比度** —— 叠加在杂色背景上的故事句，加半透明暗底 + 红色左条（`rgba(6,8,16,.42)` + `border-left`）。
6. **「混合风」守则** —— 保留魔幻底图氛围（tint 色罩）、金色有机曲线；勿因「纯构成主义」删掉有机层（作者要的是混合）。

## 案例

- **《表里之介》**（`case.html`）—— 魔幻浮空城 × 构成主义几何 × 金色有机曲线。「表/里」主题自带对立统一，天然契合对角线平衡。

## 标准流程（两段式 + 融合）

```
1. ComfyUI 出底图（anima/zimage；提示词预留文字区：subject on right, empty space left）
2. HTML 构成主义排版（本风格 → 截图出透明/成品 PNG）
3. 视觉自检迭代（geometry 结构 / 平衡 / 层级）→ 交付中文名成品
```
