# 条漫/漫画风

三格竖排 + 对白气泡 + 日式拟声词 + 旁白条。

## 达成要点

- 每格独立底图，格间留缝；底部对白条 56px 高，单条 ≤18 字
- 气泡/拟声词是**画面语言，允许叠图**（例外）：白底黑边、带尾巴、放角落
- 拟声词日式（パサッ/じゅわ/ぴくん）：`-webkit-text-stroke` 描边 + 旋转斜置
- 旁白/菜单等非漫画元素仍走侧栏/上下条，不受气泡例外

## 注意点

- 15 张级批量拼版用 `scripts/manga_panel.py`（Pillow，JPG 3-5MB），不走 HTML（成品 25MB+）
- 批量流程见 `references/multi-panel-manga.md`
