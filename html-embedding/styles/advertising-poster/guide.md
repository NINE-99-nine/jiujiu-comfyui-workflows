# 广告招贴风 · Advertising Poster（风格指导）

## 是什么

模仿**美式律师广告招贴**（《风骚律师》Saul Goodman 海报同源）——**人物占主体、文字直接印在画面上、多字体碰撞、红黑金配色、底部白色联系条、右下做旧钢印/印章**。戏谑、有梗、印刷招贴感。适合商业广告、恶搞海报、委托所/店铺宣传、事务所招贴。

## 触发词

「广告」「招贴」「律师海报」「Saul Goodman 式」「商业海报」「委托所」「事务所广告」「宣传海报」「美式海报」、以及需要**人物为主 + 多字体排版 + 有梗文案**的广告/封面。

## ★ 图层关系铁律（最高优先）

```
由下到上：
① 图1（AI 出图：人物+背景+耦合的美体字）— 占主体（约 80%），是主题
② 轻投影 veil（让叠上去的中文可读，但做成渐变、不是色块）
③ 左侧文字（多字体，直接印在画面上，文字可以侵入图片一点点）
④ 底部白色联系条（横贯全宽）
⑤ 右下角做旧钢印（可选装饰）
```

**禁止的做法**（作者明确批评过）：
- ❌ 文字裹进**不透明纯色块**面板 → 空洞丑陋，参考图是文字直接印画上
- ❌ **单一字体**排满 → 死板；要靠多字体碰撞
- ❌ **图1 主动大量留白**（左侧一片空）→ 浪费 AI 出图性能，人物细节下降；补充文字用 html 画布拓展
- ❌ 文字遮住人物脸/手/主视觉

## 核心要素

| 要素 | 达成 |
|---|---|
| **人物为主体**（约80%） | 图1：人物右侧，完整带手/半身，细节丰满；左侧墙面留出**有内容的空间**（书架/灯，不是空墙）供文字叠加 |
| **图1 耦合美体字** | 顶部大标题 `SELINA ASSOCIATES`（krea2 生成金字）+ 工牌金铭牌 `SELINA`（AI 渲，与图片绑定） |
| **多字体碰撞** | 手写草书签名（`Segoe Script`）+ 印刷衬线小字（`Georgia`）+ 书法大标题（`STXingkai`/`STKaiti`）+ 黑体标语（`SimHei`） |
| **红黑金配色** | 红 `#b01818`（标题/标语/勾）+ 黑 `#171717`（标语）+ 金 `#c9a53a`（星星/分隔线）+ 白（联系条） |
| **细节装饰** | 金星星分隔线、红色毛笔划线、红色圆勾案例图标、右下蓝色钢印 |
| **文字印画上** | 用轻投影/描边保证可读（`text-shadow`），不裹色块 |
| **白色联系条** | 底部 `#f4f1ea` 白条横贯，电话/微信/服务范围三项 + 圆图标 + 竖分隔线 |
| **做旧钢印** | 圆形蓝印 + 外环描边 + 书法字两行 + 上下星 + SVG feTurbulence 颗粒斑驳 + 倾斜 |

## 注意 / 踩坑（赛琳娜委托所多版迭代结论）

1. **先构思整体，再出图1**：图1 出图时就想好"人物居右、左侧留出有内容的空间、顶部工牌/标题",而不是先出图再硬塞文字。
2. **图1 左侧别留空墙**：留白+书架/台灯（有内容），否则像过拟合；也别让图1 人物缩太小。
3. **大字标题要有做旧颗粒**（feTurbulence），参考图的书法字有墨迹/撕裂感；干净的大字偏"印刷"。
4. **文字别和人物/顶部金字打架**：顶部金字占上部，中文文字下移到左中墙面区。
5. **钢印别太大/别挡人物**：放右下角、避开手臂，参考图钢印小、靠右下。
6. **中文字体**：用 `STXingkai`（行楷）/`STKaiti`（楷）/`FZShuTi`，做旧靠噪点；避免默认雅黑死版。
7. **文字层 ≤ 合理层级**：签名/标签/大标题/星星/标语/案例/卖点/联系条——层级分明但别堆砌到压主体。
8. **用 vision 检查**：图层顺序、文字是否压主体、多字体是否碰撞出层次、过渡是否自然、联系条横贯、钢印效果——逐项过再交付。

## 案例

- **赛琳娜 · 委托所海报**（`case.html`）—— krea2 出图1（人物右侧+工牌金字+顶部 SELINA ASSOCIATES+律所环境）→ html 左侧多字体文字 + 白色联系条 + 右下钢印。底图走 `workflows/krea2`（真人风）或 `workflows/anima`（动漫风）均可。

## 标准流程

1. 先构思最终整幅效果 → 定图1 内容（人物+耦合美体字+留出文字区）
2. krea2/anima 出图1（人物为主、细节丰满、左侧留出有内容空间、顶部/工牌美体字）
3. 写 html：多字体文字直接印画上（轻投影）+ 白色联系条 + 右下钢印 + 底部渐变
4. Edge headless 截图（window-size = body 尺寸）
5. vision 检查图层/文字压主体/多字体层次/钢印/联系条 → 中文名交付
