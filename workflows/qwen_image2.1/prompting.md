# qwen_image2.1 提示词编写指南

本指南规定 qwen_image2.1 提示词的书写方式。

一、文生图

采用自然语言描述画面内容，写明方位、内容、形态。方位指在画面何处（中间、左侧、上方、前景、远景）；内容指是什么人物或物体；形态指其外观、材质、颜色、姿态、光线等具体特征。

按画面复杂度选风格，不按喜好选：

　紧凑式 —— 1 至 3 句流畅句子。用于单一清晰的主体，如一个人像、一件物件、一处场景。语序为：主体 → 环境 → 画风 → 构图与镜头 → 光线。实测同一画面词少者构图常好于词多者，多余从句会稀释优先级。

　长观察式 —— 一段，约二十句。用于海报、版式、界面、信息图、分镜等元素多、位置需精确的画面。按下列八步写：

　1. 分出固定项与自由项。用户给的字符串、名称、数量、颜色、位置逐字保留，数量写几就是几；其余可自由发挥。
　2. 定画框。比例只由参数决定，描述里不写比例、分辨率、像素。
　3. 开篇一句：这是〈横向／纵向〉〈画风〉〈照片／海报／插画〉，主体是〈…〉，〈背景与色调〉。画风词只在这一句出现。
　4. 清点元素。每个元素先分配一个画框位置，位置短语八到十四个，分布到四角、各边与中央。
　5. 走一遍画框。多元素画面：背景 → 上带 → 主体（左、中、右各一两句）→ 下带。单一主体：背景 → 所处位置 → 头脸 → 身体与服装 → 手持物 → 其余边缘。约每三句有一句以位置开头。
　6. 文字全部写进去。按阅读顺序，每处用引号给出原文，并写明呈现方式；读不清的写成"模糊、太小看不清"，不编造。
　7. 一句光线。写明光源、方向、质感、阴影与高光。
　8. 一句收尾构图。写明平衡、色调、风格与情绪，只写一句。

二、图像参考编辑

写明三件事：指哪张图、改什么、其余如何。多图时逐图编号引用（图1、图2……）。画面其余部分的描写方式与文生图相同。

三、字数

由绘制需求决定，动态变化：短可一行，长可上千字，上限 2000 字。写足即止，写完不再复核。

四、语言

中文、英文均可。

五、嵌字

图上要出现的文字用引号标出原文，逐处写明位置与字号大小。

嵌字分两类，写法不同：

　说明性文字 —— 作为信息标签使用。只交代位置、内容、字号，不描述字形。用于规格、配料、价签、说明条。

　主体性文字 —— 字本身是画面主体，与人物、道具并列。须像描述一件物件那样写：字腔内填什么纹路或渐变、外围有无一圈厚贴边、下方投影错开的方向与颜色、背后垫着什么形状的底板、字旁缀着什么小物件、整组字的倾斜与起伏。

文字数量过多会导致字形崩坏。需删减时按此顺序：先删装饰性文字 → 再删说明性文字 → 主体性文字不删。

六、全程规矩

　现在时、第三人称、陈述句。不写"你""创建""确保""AI 应该"。
　颜色带修饰词：深藏青、灰橄榄、淡奶油，不单写"蓝""绿"。
　点明材质：拉丝金属、磨砂塑料、霜面玻璃、旧木。
　枚举而不概括：不写"若干""几个"，是三个就写三个。
　人物按可观察的表面写：体格、姿态、视线、表情、衣料颜色与面料；年龄写人生阶段，不写数字。
　用通用类别，不用品牌（"一台银色笔记本"，不写牌子）。
　物理自洽：阴影背光、倒影对得上前景、比例一致。
　抽象词等于没写："漂亮""优雅"须换成具体特征。

七、致命错误

　写成 tag 串、写角色名 —— 不认，须改写成具体特征。
　全篇不写画风与介质 —— 画风乱飘，甚至出塑料感。
　长稿不给位置 —— 元素乱堆，版式不成立。
　描述里写分辨率、比例、像素 —— 无意义，比例由参数决定。
　要出现的文字不写进引号 —— 出伪字、错字。
