# MOSS-Image 提示词规范

每次只交一种：**Caption**（纯文本）或 **Layout**（单行 JSON）。不混写、不加标题、不加解释。

## 1 判定（一句话）

谁在哪需要猜 → Layout；能一句话说清 → Caption。

| 用 Caption | 用 Layout |
|---|---|
| 单人、氛围、插画、照片、概念图 | 多人、多元素、控层级、海报版面、要嵌字、要求元素关系 |

画面复杂不等于要用 Layout，但**位置必须被钉死时一定是 Layout**。

## 2 通用铁律

1. 用户给的主体、数量、关系、介质、风格、排除项、可见文字，一字不改。
2. 画面可见文字逐字保留原语言、标点、大小写、换行。**用户指定要画的文字再长也完整照抄，永不截断、不改写、不省略**——长篇文章、整段台词一律照收，篇幅建议对它无效。指令里被引述的句子不等于要画的字。
3. 只写看得见的东西：主体、外观、环境、构图、镜头、光、色、材质、情绪。
4. 不写质量词（`masterpiece`/`8k`/`ultra detailed`/`best quality`）：工作流质量词框已清空，写进去只稀释注意力。
5. 不写过程说明、不写「此处填标题」占位、不写坐标（Layout 除外）。
6. 不重复：总述与单条互不复述，不堆同义词，不写空赞美（`eye-catching`、`perfectly balanced`、`invites viewers`）。

## 3 Caption 模式

一段自包含英文描述，是**有信息量的扩写**，不是同义改写。

按画面取用，不必逐项凑：主体与动作 / 相关外观 / 环境 / 镜头景别与视角 / 介质（照片·插画·油画·版画，一句定死）/ 光线方向与时间 / 材质反光 / 主色与情绪。

- 长度由内容决定，够用就停。短 brief 保持短，丰富 brief 展开；不凑字数、不为字数反复改写。
- 4000 字符只是**建议上限**，超过一部分或者没有达到都无伤大雅，一切遵从用户准确的需求内容。
- 只输出 caption 正文。

## 4 Layout 模式

只输出合法 JSON：首字符 `{`，末字符 `}`，无代码围栏、无注释、无 JSON 外文字。

**保结构**

1. 原样保留 schema、key 名、key 顺序、item 顺序、全部既有字段；不增删、不合并、不拆分、不复制、不重排。
2. 只允许改 `summary.caption` 与 `items[i].caption` 的**既有字符串值**；不新建缺失的 caption 字段。
3. `bbox` 数组逐位原样复制：数字、符号、顺序、长度都不动；`bbox_coord_space`、`bbox_format`、`label`、`text` 及其他非 caption 值一字不改。不归一化、不换算、不换轴、不纠正、不重定位。
4. item 与 bbox 的绑定不许换，不从「好看」倒推位置。
5. item caption 不写方位词与像素坐标（`upper-left`、`at the top`、`in the center`）——位置由 bbox 决定。
6. 带 `text` 的 item：`text` 逐字保留原语言，多长都照收；caption 只描述字形、字重、字距、材质、对比、可读性，不翻译、不改写、不加字。

**篇幅参考（不是配额，不必凑准）**

| 字段 | 参考词数 |
|---|---|
| `summary.caption` | 约 70–105 词 |
| 物件 `items[i].caption` | 约 55–85 词 |
| 文字 `items[i].caption` | 约 35–60 词 |

写不够不补空话，写超了删重复，落到区间外也没关系。整份 JSON 建议不超过约 4000 字符，**超一些不要紧，也不要求接近上限**；不要为压字数反复重写。用户要求画的长文字（整段、整篇文章）优先完整保留，篇幅让它超。

**summary 写**：介质与用途、一个自洽场景、背景层次与景深、统一视角与光向、色调与氛围、元素如何构成一张图。不堆无关地标、不做拼贴、不重复各 item 的描述。

**交付前静默自检**

1. JSON 合法；2. JSON 外无文字；3. 篇幅合理、没有为凑数注水；4. 只改了既有的两处 caption 字符串；5. bbox 与非 caption 值逐字一致；6. item 与 bbox 对应关系、顺序未变；7. 细节具体、不重复；8. 可见文字原样且完整。

## 5 本机 Layout 落法

- 坐标按**实际出图宽高**算；允许几十像素的小偏差，不必为像素级对齐反复改稿重跑。偏差到约 5% 以上才整份重算一次。
- 模型输入格式：`abs_centralized` + `yxyx`，`[y_min, x_min, y_max, x_max]`，原点在画布中心。
- 本机无 `compile_prompt.py`：用 UI 的 `Create Bounding Boxes` → `MOSS-Image Layout Prompt` 导出，或手写已换算好的 JSON。框越界会被拒绝，不会自动裁剪。
- 投喂：`--layout 布局.json --width W --height H`，**不要**用 `--prompt` / `--prompt-file`。引子会自动清空质量词与触发词文本，LoRA 仍按数组生效。

## 6 交付

Caption 写 `.txt` → `--prompt-file`；Layout 写 `.json` → `--layout`。交付只给提示词文件与一行结果。
