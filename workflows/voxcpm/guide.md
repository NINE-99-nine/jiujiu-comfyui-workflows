# VoxCPM 配音 · 使用指南

VoxCPM 语音生成工作流,黑盒调用本目录引子 `voxcpm全能工作流.py` 即可,无需关心内部节点。生成语音由**参考音频 + 训练 LoRA** 共同决定。

## 调用

```bash
python voxcpm全能工作流.py --text "台词" [参数...]
```

返回一行 JSON:`{"kind":"audio","prompt_id":…,"file":"…"}`,取 `file` 交付音频。

## 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `--text` | ✔ | 要生成的台词 |
| `--mode` | | 模式:极致克隆(默认) / 可控克隆 |
| `--control` | | 口吻,仅 `--mode 可控克隆` 时生效(极致克隆模式无此项) |
| `--lora` | | LoRA 权名,如 `浊心斯卡蒂_20260901_223158.safetensors` |
| `--voice` | | 参考音频,如 `voices/守岸人.wav` |
| `--seed` | | `-1` 随机 / 具体值固定;缺省用模板值 |
| `--name` | | 交付文件名 |

## 模式

- **极致克隆**(默认):只改 `--text`,其余全部保持默认。**此模式没有 `--control` 参数**。
- **可控克隆**:`--mode 可控克隆`,此时通过 `--control` 描述口吻。

## 全默认形态

**形态一(全默认,默认出日语/英文)**:浊心斯卡蒂参考音频 + 其 LoRA + 极致克隆。只改 `--text`,其余默认。此形态**只能生成日语和英文**。

```bash
python voxcpm全能工作流.py --text "台词"
```

**形态二(全默认,生成中文)**:只把参考音频换成守岸人的(LoRA 不变,仍为默认浊心斯卡蒂),只填 `--text` + `--voice`。

```bash
python voxcpm全能工作流.py --text "中文台词" --voice voices/守岸人.wav
```

## 案例

- 换 LoRA:`--lora 库珀花环.safetensors`
- 换参考音频:`--voice voices/铅玻璃.mp3`
- 可控克隆:`--mode 可控克隆 --control "低沉沙哑的成熟女声,带着倦怠和一丝嘲讽"`

## 注意

- 生成前先查 `/queue`,作者跑图时禁开独立 GPU 进程(DEVICE_LOST 纪律);提交后查 `node_errors: {}`。
- 首次生成含 graph capture(~50s 一次性),不是卡死;同模型实例后续免。
- 换 LoRA = 模型重载 + 重新 capture(~60s);换参考音频 = 去噪/ASR/encode 重跑(~5-10s);同参考音频连续生成命中缓存(~7s)。
- 交付文件直接取返回的 `file`,用有意义中文名交付,禁自动编号。
