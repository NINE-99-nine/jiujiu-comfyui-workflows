## ① 风格定位

一句话：**字不是标签，字是主体。** 普通海报把字"排"上去，这套风格把字"画"出来——字面有填充纹路、外面有厚贴边、下面有错位投影、背后有承托底图形、旁边还缀着小物件。

判据：**这张海报如果把主字抠掉，画面会塌一半**——那它就是这套风格；如果主字换成别的字体也不影响观感，那它只是 A 类说明位。

**用在哪**：饮品/食品/美妆等消费品的宣传海报、新品预告、门店物料；需要"一眼记住产品名"的场合。

## ② 提示词结构 / 要点

### 1. 主字（B 类设计字）——这套风格的核心，必须逐项写

不要只写"写一行大标题「XX」"。要像**描述一件道具那样**把字写出来，六件齐写：

| 项 | 要写什么 | 术语 |
|---|---|---|
| **字面填充** | 用什么质感填字腔（本产品自身的纹路最好用）、有没有高光、渐变方向 | patterned / textured letterforms |
| **厚白贴边** | 一圈厚实的纯白描边，"像从白纸上剪下来的贴纸" | **keyline** / die-cut border |
| **错位投影** | 与字形略微错开、颜色取主题深色，制造"立在画面上"的厚度 | **offset shadow** |
| **承托底图** | 字垫在什么形状的底板上（云朵/徽章/飘带），底板的边、描边、投影 | **shape backing** |
| **字旁小物件** | 贴着字的边缘点缀什么（花瓣/叶片/珍珠/星星/气泡），强调"被托着" | accents |
| **整体姿态** | 字与字之间的间距、整组字的倾斜与起伏（"跳动而活泼"） | — |

**变体手法**：让主字的某一笔**延伸出去搭在实物上**（如「奶」的一笔搭在杯壁上）——字与实物产生连接，画面就不散。

### 2. 人物

- **图生图**：外貌交给参考图，提示词里只写「保持图1的长相/发型/体型/服装不变」+ 姿态动作。
- **文生图**：原创 OC 写精确外观（发/瞳/肤/脸型/身形含数字/服装逐项）；有官方角色串的角色才只写角色串。
- 景别要与用途匹配：**上半身特写**（产品为主）或**全身立绘**（人物为主）。写清"从头顶到大腿中部完整入画"这类范围。

### 3. 背景——**必须有景深层次**（本风格最容易偷懒的地方）

🔴 **空白背景 = 没层次 = 画面立不住。** 至少写**四层**：

| 层 | 放什么 | 处理 |
|---|---|---|
| **前景** | 桌角、实物、散落的小物 | 最清晰 |
| **中景** | 人物本体 | 主体清晰 |
| **中后景** | 装饰物（花架、藤椅、书架） | 略虚 |
| **远景** | 空间纵深（玻璃顶、拱窗、街景） | 最虚 |

再补：**光的方向 + 时间 + 空气**（浮尘、飘落的花瓣），并给一个**带特征的场景**（玻璃花房 / 咖啡馆窗边 / 木质吧台），不要写"简单的背景"。

### 4. A 类说明位——只交代位置、内容、字号层级

写完 B 类主字，其余文字全部按 A 类写：**哪里写什么字 + 字号大小**，不描述字的样子。典型四处：缎带副标、圆角信息卡（做法/配料/参数）、底部横贯卖点长条、右下价签 + 「新品」小燕尾标签。

### 5. 色彩预算

主色取**产品本身的颜色**（本图 = 奶白 + 淡薄荷绿 + 嫩绿 + 象牙白），辅助色给环境（浅青灰 / 暖木色）。**点缀色只给价签与珍珠**这样的极小面积；明确禁霓虹与大面积高饱和。

### 6. 收尾构图段（必写）

景别 + 机位 + 人物位置 + 留白比例 + **三层景深各自清晰度**。不写 = 模型自由发挥。

### 7. 🔴 版式是自由的——学的是「字怎么画」，不是「字放哪」

这份文档教的是**字的画法**（填充 / 贴边 / 投影 / 承托 / 小物 / 姿态），**不是一套版式模板**。以下四件事每一张都该跟着场景重新想：

| 项 | 可以怎么变 |
|---|---|
| **底图形状** | 云朵 / 徽章 / 波浪 / 浮板 / 救生圈 / 沙地 / 水面 / 撕纸边……按场景选，**甚至可以不要底图** |
| **字的位置** | 聚在一侧 / **散落各处** / 绕着人物 / **半个字浸在水里** / 压在云前 / 倚在实物上——都可以 |
| **说明位形式** | 飘带 / 信息卡 / 浮板 / 木牌 / **地面上的水渍** / 瓷砖刻字……跟着场景长 |
| **字的数量与层级** | 一个大主字 / 四个字各自独立 / 主字拆开分处画面四角都可以 |

**判据**：看这些字**是不是为这个场景长出来的**。**如果换个题材照样能用，那它就是模板，不是设计。**

⚠️ **反面教材（本库自己的教训）**：曾连出三张都用「左字 + 云朵底图 + 飘带副标 + 左下信息卡 + 底部长条 + 右下价签」——那就是把示例里的版式当成了模板照搬，**只学到壳**。修法见上面「散落版」样本。

## ④ 复用要点

| 换什么 | 改哪里 |
|---|---|
| **换产品** | 主字内容 + 字面的填充质感（换成产品自身的纹路）+ 人物手里那件实物 + 信息卡里的做法/配料三行 + 底部卖点长条 |
| **换主色** | 主字渐变、云朵底板、飘带、底部长条的色系整体换掉，保留"字面填产品色 + 白贴边 + 深色错位影"的结构 |
| **换底图形状** | 云朵 → 徽章 / 花瓣形 / 圆角矩形 / 撕纸边；保持"底板带细描边 + 投影 + 比字大一圈" |
| **换场景** | 玻璃花房 → 咖啡馆窗边 / 木质吧台 / 街角店铺 / 野餐草地。**四层景深的结构不变**（前景实物→中景人物→中后景装饰→远景纵深） |
| **换字体质感** | 果冻气泡字 → 奶油厚涂 / 金属浮雕 / 霓虹管 / 手写毛笔；换的是"填充方式"，六件（填充/贴边/投影/底板/物件/姿态）仍要齐写 |
| **换人物** | 图生图 → 只写"保持图1不变"+姿态；文生图 → 换人物外观段。**注意原创 OC 要写精确外观，有角色串的只写角色串** |
| **只出产品不出人** | 删人物段，主字放大占画面主体，背景改为四层产品场景（前景道具→中景产品→中后景装饰→远景纵深） |

## 术语来源

「说明型 / 设计型」的分野依据字体排印学的两条正交轴（2026-10-11 核实）：

- **按用途**：`Text type`（正文体）↔ `Display type`（展示体，Monotype 定义"用于横幅、标题等大字号的字体"）
- **按生产方式**：`Typography`（用现成字体排版）↔ `Lettering`（**画字**，维基："Lettering is created as an image... created with a specific word in mind"）↔ `Calligraphy`（一笔书写）

**本风格 = `Display lettering`**（中文：美术字 / 字体设计）。
