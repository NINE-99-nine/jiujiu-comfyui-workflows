> **风格定位**：绚烂花式的**暗调**立绘人设卡——深色天鹅绒底 + 金色巴洛克镂空花纹 + 猩红蔷薇与银白月相，中央全身立绘，四周环绕属性面板、口癖 / 喜好标签牌与引线标注，前中后三层明确叠压穿插。与旧「干净平面人设卡」相反：**把角色的高调白留在人身上，卡面整体翻成暗调**，靠花饰与图层撑起华丽。

## 一、提示词结构 / 要点

### 1. 后中前三层骨架（必须分段写明叠压关系）

| 层 | 内容 | 写法要点 |
|---|---|---|
| **后层**<br>底纹与花窗 | 天鹅绒渐变底 → 金色巴洛克卷草藤蔓 → 满月 + 哥特尖拱花窗 → 青色光晕 | 底写「深墨绿黑到深紫黑」的**渐变**底色 + 细微织物颗粒；卷草写「从四角向中心蔓延 / 纤细繁复 / 镂空通透」；藤蔓间点缀蔷薇、细叶、星点；**必须加一句「密集而不压过主体」**，否则背景反客为主 |
| **中层**<br>角色立绘 | 全身立绘，占画面高度约 3/4，微侧身、重心落一侧腿 | 人物外观与服装**逐项写全**（见本节 6 的形象锚定清单）；末句加「胸前有一道从左上斜向右下的硬边暗带」——这条硬边暗带是提升照片感的关键 |
| **前层**<br>花饰与穿插 | 蔷薇枝条、金色卷草、缎带丝带、花瓣 / 星点 / 棋盘格碎块 / 黑蝴蝶 / 青色尘点 | **逐项写清谁压谁**：蔷薇叶片「压在裙摆边缘与鞋面上」、金卷草「越过她甩开的长发末梢」、丝带「搭在裙摆褶皱上」。收口句**「层层穿插，形成明显的前中后叠压关系」不可删**——删了模型会把装饰排成平面贴图 |

### 2. 信息区画法（三块，位置固定）

- **属性面板（左）**：半透明**深色玻璃**质感 + 金色细描边 + 四角小切角 + 内壁极淡青色反光。**不要实心卡片、不要重投影拟物 UI**——会压死画面。
  - 面板顶一行小标题（如「属性」），下面逐行条目（每行 `标签：内容`）。
  - 数值条 = **等宽小方格组成的分格刻度条**（不是连续进度条），点亮格猩红、未点亮暗灰；格数与服装的棋盘格同构呼应，是这套设计语言的暗线。
- **标签牌（右）**：悬挂式**绶带牌**，金色描边、两端卷草纹收尾；牌头顶端写类别名（如「口癖」「喜好」），下方正文用略大的字排 2 行。
- **引线标注（底）**：极细金色引线从小圆点出发指向人物相应部位，末端用**最小号字**标注部位与单品名。

### 3. 嵌字分级与崩字削减顺序

26 处中文一次投放属于**极限测试**（qwen_image2.1 才吃得下）。建议第一轮全量跑，崩字则按级削减：

| 级 | 数量 | 内容 | 崩字处理 |
|---|---|---|---|
| **骨架级** | 7 处 | 角色名、面板标题、三条数值条标签（算力 / 魔力 / 血量）、两个牌头（口癖 / 喜好） | **永远保住** |
| **内容级** | 11 处 | 拉丁副名、作品与小字行、面板五条条目、两句台词、喜好两行 | 第二步砍 |
| **装饰级** | 8 处 | 六条引线标注、左下角编号、右下角角标 | **第一步砍** |

### 4. 色彩预算

深墨绿黑 / 深紫黑打底（体量）· 金为主装饰色（高级感开关）· 猩红为视觉焦点 · 银白来自头发与月光 · 青灰用于阴影与色散。人物自身的白与黑保持高对比；**红只出现在眼瞳、丝带、蔷薇与数值条上**，四处呼应。光源来自正上方偏后的满月，发顶 / 肩线 / 裙摆上缘有冷白轮廓光。

### 5. 后期质感（这张卡的"贵"主要来自这里）

强烈柔光泛光（亮部微微溢出）+ **三到六像素的红青色散描边**（出现在发丝边缘、肩线、丝带与手指）+ 均匀胶片颗粒噪点 + 轻微镜头光晕。收尾句用「华丽而略带失真的收藏级插画气质」。

### 6. 形象锚定清单（换角色时逐项替换）

发色（极浅银白、暗部带冷青灰反光）· 头顶蓬松翘起的碎发 · 两侧三股麻花辫（**十字编织格纹清晰可见**）· 其余长发向左右甩开成大回环、发梢细而分叉 · 苍白偏冷的肤色 + 淡粉腮红 · 鲜红眼瞳（**瞳孔中有星形亮斑**）· 慵懒清冷的眼神 / 鼻与嘴极小 · 白色立领衬衫式连衣裙上身（小立领 + 浅色圆纽扣）· **大号黑色缎面蝴蝶结**（领下）+ 中轴线上等距三个较小的黑缎面蝴蝶结 · 左右胸口红色细丝带蝴蝶结 + 垂下两条细长飘带 · 纵向细密压褶的白色胸襟面板 · 肩到胸前的宽大圆形荷叶边（波浪锯齿边）· 长袖微蓬 + 白色荷叶边袖口 · 黑色宽腰封 · 高腰大喇叭形**黑白棋盘格百褶裙**（格纹随褶产生透视与明暗变化）· 裙下露一截深灰黑短裤 + 一小块青蓝色蝴蝶印花 · 黑色不透明连裤袜（膝盖与小腿正面纵向长条高光）· 黑色亮面圆头玛丽珍鞋 + 黄铜色小方扣 · 双手自然垂在身侧、手指纤细。

### 7. 投喂参数

竖版 **3:4 或 2:3**，总像素预算 **2.0**（≈1229×1638）；**steps 默认 20**（cfg 1、euler + simple）——本风格嵌字点多，确需更精致时可提到 30～40，但别静默抬高。**不要把参考图当 `<image1>` 传进去**——它会倾向保留白底高调构图；本风格是全文字重绘，人物形象已在文字里写全。
