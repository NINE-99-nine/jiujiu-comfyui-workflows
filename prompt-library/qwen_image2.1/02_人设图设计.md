# 02 · 人设图设计（把角色图写成一张角色设定资料页）


## ① 风格定位

- **这是什么**：把**一张角色图（立绘 / 写真 / CG）**升维成**一页角色设定资料（人设图）**的提示词写法。输入是"一个角色的一张图"，输出是"这个角色的一整页资料"。
- **核心认识（P0）**：🔴 **人设图不是画风问题，是版式问题**。同一套骨架，画风句写成「跟随参考图」即可（退一步才是写死一个锚词）；真正决定"像不像人设图"的是三件事——**① 分区骨架 ② 每块里放什么 ③ 文字怎么标**。画风只影响气质，版式才决定成败。
- **本案例要教的是**：写哪些方面、每方面写到什么颗粒度，就足够让模型自己长出一张好看的人设图；**不是**逐字背诵某一份范文。
- **两种已验证的密度取向**（按需求选，别一刀切）：
  | 取向 | 幅面 | 区块数 | 气质 | 适合 |
  |---|---|---|---|---|
  | **A · 全信息面板式** | 21:9 / 16:9 宽幅 | 12–15 块 | 资料全、热闹、设定集内页感 | 完整角色设定、多视角多特写 |
  | **B · 写实资料页式** | 16:9 / 3:2 | 6–8 块 | 留白足、主视觉大、干净 | 主视觉优先、写真感、单页展示 |

## ② 提示词结构 / 要点（要写到什么，共七个方面）

写人设图提示词，按下面七项逐项落地——**缺哪项，画面就少哪块**。

### 1. 先声明「这是什么页」＋ 画布方向（第一句就写）
例：`一张横向排列的角色设定资料页（character design sheet）……`
不给这个声明，模型只会给你一张普通立绘。参考图是竖版而目标画布是横版时，追加一句 `重新排布成一张横向的资料页`。

### 2. 底材 / 边框 / 装饰（定整页气质）
底色（米白象牙 / 奶油 / 浅灰）、纸张纹理、四周边框（细金线 / 浅棕线）、四角装饰（花卉藤蔓 / 叶片 / 几何描线）、每块面板的形式（浅底 + 圆角矩形 + 细金边）、块与块之间的留白与分隔线。

### 3. 分区骨架（人设图的脊梁，最关键）
逐块写清 **位置 + 占位 + 内容 + 小标题**。两套已验证骨架：

- **A · 全环绕式**：`顶部标题栏` ／ `中央主视觉（占最大面积、纵向贯穿）` ／ `左侧栏 3–4 块` ／ `右侧栏 3–5 块` ／ `底部 2–3 块`
- **B · 左主右辅式**：`顶部细标题栏` ／ `左侧半幅主视觉` ／ `右上 2 块` ／ `右下 2 块` ／ `底部资料条`

🔴 主视觉必须写明「占最大面积 / 纵向贯穿 / 最高精度」，否则模型会把资源摊平，整页都平。

### 4. 每块里到底放什么（人设图的信息来源）
| 块 | 要写到的东西 | 颗粒度示例 |
|---|---|---|
| 视角块 | 正面 / 侧面 / 背面（或两视角），并写明「背面能看到什么」 | 「背面能看清麻花辫的编法、裙摆收口与肩带走向」 |
| 表情块 | 给**具体表情词**，不要写"各种表情" | 「浅笑 Smile」「害羞 Shy」「惊讶 Surprised」 |
| 服装块 | **逐件列单品**（含画面里没出现的层，如内衣、袜子） | 连衣裙 / 珍珠颈饰 / 花环发饰 / 腕表 / 鞋袜 / 内衣 |
| 材质块 | 列材质名 | 碎花棉布 / 珍珠光泽 / 薄纱 / 缎面 / 弹力针织 |
| 细节块 | 列部位 | 眼睛 / 编发与缎带 / 发饰 / 裙摆收口 |
| 资料块 | 列字段（字段名 + 值都要给） | 姓名 / 年龄 / 身高 / 体重 / 体型 / 生日 / 身份 / 性格 |
| 场景块 | 写场景元素 | 木栈道 / 白色碎石 / 棕榈 / 遮阳伞 / 薄云天空 |
| 小物块 | 列物件 | 腕表 / 唇膏 / 小镜子 / 信纸 / 甜品 |

### 5. 文字策略（P0：大字排满 · 装饰级小字全砍）

🔴 **本页的门面不是"写多少字"，是"哪些字写、哪些字不写"。** 先把文字分成两级，再动笔：

| 级别 | 包含 | 处理 |
|---|---|---|
| **骨架级 / 内容级** | 顶部大标题（中文＋英文并排）｜副题｜**每个面板的中英双语栏目标题**｜三视图与表情集的下方标注｜资料块的字段行 | **必写，且字号要大**——不写就废掉整页 |
| **装饰级** | 面板里每一张小图、每一件道具**下方的物件名称**｜英文辅助小注｜角落装饰小字 | **一律不写**——它们撑不了版面，却是伪字的主要来源 |

- **主动加几处大号装饰字**来补设计感（砍了小字容易显得空）：中央立绘**两侧的竖排名号**（左中文名／右英文名或编号）、**最底部一条横贯画面的装饰长条**（英文名 ・ 编号/称号）；顶部标题与副题之间可加一条金色细线装饰。
- **中英双语栏目名比纯中文更稳**——英文给模型更强的锚点；只写中文时栏目名更容易出错字（实测：「核心道具」被写成「背心道具」、「背景设定」被写成「核景设定」）。
- 总纲要原样写进提示词（**不给这段，模型会到处补小字并写成伪字**）：
  `只写下面列出的这些文字，一处不多、一处不少；面板里的每一张小图、每一件道具都只画出来、绝不在图下写名称；除清单之外，画面里不得出现任何其他文字、编号、水印、小注、英文辅助说明，也不得出现任何形似汉字的伪字、错字或乱码笔画。`
  再补一句堵住零星字母：`每一张小图的内部（人物的衣服上、书架上、道具上、场景里）一律不许出现任何文字、字母或符号。`
- **生僻词换常用词**：`书案文具` 一类不常见的搭配容易被写错（实测写成「书集文具」）；底部小块的标题尽量用 `文具 STATIONERY`、`随身物件 PERSONAL ITEMS` 这类常见搭配。
- 🔴 **实测：清晰度的杠杆是"文字点数量 + 字号级别"，不是步数。** 同一稿、同一 seed、只把步数从 40 提到 50：**骨架级文字两版都清晰**，**装饰级小标签两版都糊成伪字**（只是换了一批错法）；而把装饰级全砍、并主动加装饰大字之后，**30 步即全页无伪字**。→ 崩字时先砍文字点，别先加步数。
- **步数**：当前默认 **20 步**（标准模型，cfg 1、euler + simple）。没额外说明就用 20；人设图属于文字点较多的题材，确需更精致时可提到 **30～40**，但要先说明、别静默抬高。
- 崩字时的收敛顺序：**装饰级（小物名 / 英文辅助）→ 内容级（材质名 / 细节名）→ 骨架级（栏目标题、资料行，绝不砍）**。

### 6. 画风句（🔴 默认跟随参考图，不写死风格词）

- **默认写法（优先用这条）**：`整页的画风、线稿、上色方式与质感，必须与参考图（图 1）完全一致——参考图是什么画风，成图就保持什么画风，不要自行改变画风、不要套用任何固定的风格流派。`
  → 好处：换参考图，画风自动跟着换。**写死「日系」之类的风格词会让参考图是 CG 或写实时也硬生成日系**，稿子就不再跟参考图走了。
- **画风句只写一遍**（主视觉段 + 末尾一句整体风格），不要每块都重复，否则画风会打架。
- **小图 / 特写块 / 场景块要单独再压一句**：模型常把主体跟住了参考图，却在材质块、纹样块、右下场景小图上跑成写实／照片感。补上一句：
  `画面里的每一部分都必须用参考图的画法画出来，包括所有小立绘、所有材质／纹样特写的方块、右下角的场景小图；不要出现照片级纹理、写实渲染、厚涂或 3D 感。`
  （实测：不补这句时，主体是平涂、材质块与场景仍会偏写实；改成"纹样特写"这类纯图案的块也能少跑偏。）
- **只有参考图本身没有画风信息时**（是照片、纯色图、多人混排），才退回写死一个锚词：
  - 日系：干净线稿、赛璐璐上色、平涂＋淡雅阴影
  - 写实：真实皮肤质感（毛孔 / 绒毛 / 晒痕）、自然光、浅景深、轻微胶片颗粒；**明确排除**「动漫线稿 / 赛璐璐上色 / 二次元比例」
  - CG：厚涂质感、电影级柔光、逆光与飘落花瓣

### 7. 收尾一句压住填充冲动
`信息量适中 / 丰满，区块之间留白均匀，不要密集成表格。`

## ③ 完整示例（两例原文，可直接投喂）

### 案例 A · 16:9 全信息面板式（画风跟随参考图 · 大字排满小字全砍）

```
重新排布成一张横向的角色设定资料集（人设图／设定集内页）：把参考图中那位少女作为主角，做成「中央大立绘 + 四周分栏面板」的杂志式信息图版式，横版排版；米白色象牙底、带极浅的古典纸张纹理，四周是金色与浅棕色的细线边框，四角有花卉藤蔓装饰；面板为浅色底、圆角矩形、细金边。全页文字全部是字号偏大、笔画清晰、准确可读的标题级文字，不写任何细小标签。

🔴 画风（最高优先）：整页的画风、线稿、上色方式与质感，必须与参考图（图 1）完全一致——线稿干净、平涂上色配简化的两段式阴影、色彩明快。参考图是二维插画，所以**画面里的每一部分都必须用插画的方式画出来**：包括所有小立绘、所有材质特写的方块、右下角的场景小图，统统保持同样的平涂线稿画法；不要出现照片级纹理、写实渲染、厚涂、3D 或真实材质摄影感，也不要套用任何与参考图不同的风格流派。

🔴 文字策略（严格执行）：只写下面列出的这些文字，一处不多、一处不少；面板里的每一张小图、每一件道具都只画出来、绝不在图下写名称；除清单之外，画面里不得出现任何其他文字、编号、水印、小注、英文辅助说明，也不得出现任何形似汉字的伪字、错字或乱码笔画。

核心人物（必须与参考图完全一致）：一位贵族千金少女，十六七岁的年纪，身高约 158 厘米，身形纤细挺拔、肩背笔直、四肢修长；雪白色的长发垂至腰际、发质柔顺有光泽，其中一侧编成一条侧辫搭在肩上、辫尾用一根红色细绳系住；猩红色的眼眸清澈而冷淡、眼神平静疏离；冷白皮肤、五官精致立体、鼻梁挺秀、下颌线清晰、嘴唇薄而色淡；气质清冷矜持、目下无尘。她上身是一件白色长袖竖条纹夏衫，从领口到肋间缀着一排由大到小渐变的黑色丝带蝴蝶结，右胸有一朵蓬松的荷叶边褶花；下身是一条黑白格子的高腰百褶裙，裙摆到膝盖上方；腿上是一层厚黑丝连裤袜，半透塑型、勒出笔直的腿线；脚穿一双黑色的玛丽珍鞋，鞋面一根横带配小圆扣。

画面版式（逐块排布）：
- 顶部标题栏：正中一行很大的中文标题「赛琳娜」，紧挨着右侧一行同样大的英文「SERENA」，两个字块都加金色花纹细框；下面一行清秀的副题「南丁格尔家 · 独女 ／ NOBLE LADY」；标题左右两侧各伸出一条金色细线装饰。
- 中央主视觉：画面正中一张最大的全身正面立绘（纵向占画面大部分高度、最高精度）——少女站在干净柔和的米白到浅灰渐变背景前，双手交叠在身前、站姿端正、微微侧头看向画外，光从侧前方打过来，头发、衣料与黑丝上都有干净的高光，脚下一层极淡的投影。立绘两侧的留白里各放一行很大的竖排装饰文字：左侧竖排中文「赛琳娜」，右侧竖排英文「SERENA」，字体工整、笔画清晰、字号很大。
- 左侧一栏自上而下四块面板（每块只写中英双语的栏目标题，格内小图不写名）：
  「三视图 THREE VIEWS」—— 正面／侧面／背面三个全身小立绘并排，三张图下方分别标注「正面」「侧面」「背面」；背面能看清那条侧辫的走向、夏衫背面的剪裁与百褶裙的褶线。
  「表情集 EXPRESSION」—— 四个圆形头像并排，下方分别标注「冷淡」「羞怯」「惊讶」「恼怒」。
  「核心道具 KEY ITEMS」—— 四件道具并排画出来：黑色丝带蝴蝶结、红色细绳发结、一支钢笔、一封封好的信笺。

- 右侧一栏自上而下四块面板（每块只写中英双语的栏目标题）：
  「服装分层 CLOTHING LAYERS」—— 五件单品并排画出来：白色长袖竖条纹夏衫、渐变的黑色丝带蝴蝶结、黑白格子高腰百褶裙、厚黑丝连裤袜、黑色玛丽珍鞋。

整体风格：与参考图完全一致的精致二维插画风格，工整华丽、排布有序、留白得当；主色为象牙白＋金色＋黑白点缀、以猩红色作为点睛；中央立绘最醒目、四周资料围绕展开，横构图宽幅；版面要有杂志内页的设计感，不要密集成表格。
```

## ④ 复用要点（学"方面"，不是复刻字面）

- **骨架照搬、内容全换**：留住"哪一块放在哪、这块里放什么、字怎么标"，把角色、服装、场景、字段通通换掉，就是一张全新的人设图。
- **换角色** → 只改三段：`人物特征段` ＋ `资料块字段值` ＋ `服装 / 材质 / 细节块的单品清单`。
- **换画风** → 什么都不用改：画风写成「与参考图完全一致，完全跟随参考图，不套用任何固定风格」，参考图换掉画风就跟着换（**不要把「日系」之类的画风词写死在稿子里**）。
- **换幅面** → 21:9 / 16:9 走"中央主视觉 + 左右双栏"（案例 A）；16:9 也可走"左主右辅"；3:2 / 4:3 走"上主下栏"。
- **从角色图出发（本案例主用法）** → 把参考图作为编辑目标（`--images` 第一张）＋ 画布加 `--custom-size`（否则被参考图尺寸锁死）＋ 提示词首句写"重新排布成横向资料页"＋ 主视觉要求"高精度 CG／写真"。竖版参考图 → 横版资料页，这条路已实测可行。
- 🔴 **不是逐字复刻**：示例里的名字、身高、道具全是占位。要继承的是**"写到哪些方面、每方面写到什么颗粒度"**——写到了，各种题材、各种角色、各种画风都能长出好看的人设图；只抄字面，换个角色就崩。
