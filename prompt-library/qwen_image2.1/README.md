# qwen_image2.1 · 优质提示词风格库

> qwen_image2.1（Qwen-Image 2.1，text encoder = Qwen3VL-8B）专属的**可复刻成品提示词范式库**：存放"写好的高质量提示词长什么样、怎么照着复刻"，供日后直接取用与二次创作。
>
> **与工作流侧分工（勿混）**：本目录管「**成品范式 + 复刻资料**」；提示词的**书写格式总纲**见 `workflows/qwen_image2.1/prompting.md`（各风格文档仍带自己的「① 结构 / 要点」）；**提交与执行**走引子 `workflows/qwen_image2.1/qwen_image2.1汇总_api.py`，参数与节点见 `workflows/qwen_image2.1/guide.md`。

## 一、分类机制（与 krea2 / anima 同一套，禁止乱放）

1. **一个风格 = 一份 `.md` 文档**，文件名统一 `NN_风格名.md`（两位序号前缀 + 中文风格名，如 `01_立绘卡片风格编辑.md`）。
2. 新增风格：**追加下一个空序号**，并把它补进下方「风格索引」表——**索引与文件必须同步**。
3. 每份风格文档**必须**含以下四段（顺序固定），保证一律按同一结构复刻：
   - **① 风格定位**：一句话说清是什么风格、适用什么画面、注意什么。
   - **② 提示词结构 / 要点**：这套风格怎么写（图层骨架 / 构图 / 色彩 / 材质 / 文字策略 / 嵌字分级等）。
   - **③ 完整示例**：可直接投喂的**原文**，标注比例、像素预算、采样参数与嵌字清单。
   - **④ 复用要点**：换主体 / 换主题 / 换面板 / 换装饰 / 换比例时改哪里。
4. **本目录不放**：工作流节点与提交方式（→ `workflows/qwen_image2.1/guide.md`）、跨模型通用词条、负面提示词（一律不入库）。

## 二、模型提示词口味（qwen_image2.1 速查）

| 维度 | 脾气 |
|---|---|
| 语法 | **段落式自然语言**，不是 tag 堆砌——text encoder 是 Qwen3VL-8B，与 krea2 同源，吃长句、读布局 |
| 长度 | 官方支持 **1k token 级指令**；短提示词只给"通用图"，越长越准。本库成品稿约 1.7k 汉字 |
| 中文 | **母语级**。中文文字渲染强于英文——**嵌字优先中文** |
| 编辑 | 图 1 = 编辑目标，图 2…10+ 为参考（节点实际声明到 16 张）；API 里直接写 `images.image_N`，无需 VAEEncode 串接 |
| 参数 | 官方路径 **cfg = 1**、euler + simple；**本机用标准模型（非 turbo），模板默认 20 步**。🔴 **没有额外说明就用 20 步**——用户明说就照做；这张确实需要更精致（精细排版、文字点多）时可以适度提高（30～40），但**先说明、且不许静默抬高到 40/50**（详见 `workflows/qwen_image2.1/guide.md` 第六节第 4 条） |
| 尺寸 | **输出画布**由 ResolutionSelector 定（`--ratio` × `--megapixels`，文生图）；`--resolution` 是**输入侧**参考图的总像素预算（默认 1024），不是宽或高。原生 2K，上限 4MP |
| 提交 | `python workflows/qwen_image2.1/qwen_image2.1汇总_api.py --prompt-file 词.txt`（**无图=文生图 / 有图=编辑**，加 `--custom-size` 可自定义图生图画布） |
| 透明底 | 专用句式：`This is an RGBA format image with transparency. [描述]. The image has an alpha channel and a transparent background.`（存 PNG 才留得住 alpha） |
| 负向词 | **cfg = 1 时 negative_prompt 不生效**；要写负向就得抬高 cfg，官方路径不推荐 |

## 四、样本图归档（`samples/`）

> 目的：看风格案例时能**直接对照形象与版式的实际样本**，一一对应、无需另找文件。

1. **一个风格至少一份样本图**；同一风格多次产出全部保留，靠文件名区分（命名：`NN_风格名[_版本]_主体_日期.png`）。
2. **新增样本后三件事（缺一不可）**：
   - ① 图放入本目录 `samples/`；
   - ② 在**对应风格文档顶部**挂一行图片链接，并注明出处与参数（原文出处／比例／像素预算／steps／日期）；
   - ③ 更新上方「风格索引」表的**样本图**列。
3. 样本图是**实际依据**（可能是作者提供的高调参考图，也可能是本库实出成品），不参与提示词正文；替换或删除前先与作者确认。

## 五、维护约定

- 新增 / 修改风格文档后，**同步更新本索引**。
- 正文用中文，提示词原文一律中文稿（qwen_image2.1 的中文渲染是其强项）。
- 每份风格文档末尾记一句**来源 / 定稿时间**。
- 本库属 `jiujiu-comfyui-workflows` 技能库（git 化）——改完即 commit，**不产生 `.bak`**，Hermes 侧与 DSH 侧（`.agents/skills/jiujiu-comfyui-workflows`）同步双 commit。
