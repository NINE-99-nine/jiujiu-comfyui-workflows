# anima · 优质提示词风格库

> anima（GGUF 基座 + turbo UNET + Qwen3 CLIP，tag 与自然语言交并、**纯英文**）专属的**可复刻成品提示词范式库**：存放"写好的高质量提示词长什么样、怎么照着复刻"，供日后直接取用与二次创作。
>
> **与工作流侧分工（勿混）**：`workflows/anima/guide.md` 管「**工作流使用指南 + 提交方式**」、`workflows/anima/references/anima-prompt-rules.md` 管「**书写格式规范**」；本目录管「**成品范式 + 复刻资料**」。

## 一、分类机制（新风格一律按此归置，禁止乱放）

1. **一个风格 = 一份 `.md` 文档**，文件名统一 `NN_风格名.md`（两位序号前缀 + 中文风格名，如 `01_杂志封面贴纸网点海报.md`）。
2. 新增风格：**追加下一个空序号**，并把它补进下方「风格索引」表——**索引与文件必须同步**。
3. 每份风格文档**必须**含以下四段（顺序固定），保证一律按同一结构复刻：
   - **① 风格定位**：一句话说清是什么风格、适用什么画面、注意什么。
   - **② 提示词结构/要点**：这套风格怎么写（分层/版式/线条/色块/文字策略/网点等）。
   - **③ 完整示例**：可直接投喂 anima 的原文（英文），标注比例与文字策略。
   - **④ 复用要点**：换主体/换色/换场景时改哪里。
4. **本目录不放**：书写格式规范（→ `workflows/anima/references/anima-prompt-rules.md`）、工作流节点与提交方式（→ `workflows/anima/guide.md`）、跨模型通用词条。
5. 负面提示词一律不入库；**成案例原文自带的排除段（`exclude:` 行）除外**——那是该提示词正文的一部分，照抄保留。

## 三、参考图归档（`samples/`）

> 目的：看风格案例时能**直接对照该风格的实际出图效果**（anima 侧对标基准），一一对应、无需另找文件。

1. **一个风格一份参考图**（同一风格多次出图时全部保留，靠文件名区分；命名：`NN_风格名[_版本|_参考图]_主体_日期.png`）。
2. **新增出图后三件事（缺一不可）**：
   - ① 图放入本目录 `samples/`（用**原始 PNG**，不用转码/压缩副本）；
   - ② 在**对应风格文档顶部**挂一行图片链接，并注明出图信息（**读 PNG 元数据实查**：底模／放大链／[19] 分辨率与成图尺寸／激活 LoRA／提示词来源与长度）；
   - ③ 更新上方「风格索引」表的**参考图**列。
3. 参考图是**实出成品的证据**，不参与提示词正文；替换或删除前先与作者确认。

## 四、维护约定

- 新增/修改风格文档后，**同步更新本索引**。
- 正文用中文；**提示词原文英文照抄，一字不改**（含标点与分段）。
- 每份风格文档末尾记一句**来源/定稿时间**。
