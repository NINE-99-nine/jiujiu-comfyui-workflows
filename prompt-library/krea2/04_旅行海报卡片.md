# 04 · 旅行海报卡片（白贴边平面剪纸 × 旅游vlog海报卡片）

> **风格定位**：白贴边平面剪纸/贴纸拼贴 × 旅游 vlog 海报卡片设计——把「明信片/旅游海报」当版式来画：四边装饰纹样 + 左侧旅行文字版块 + 中央偏右一个**白框窗口**内嵌主体与旅行地实景，外围散布白 die-cut 边贴纸与平面剪纸剪影，夹入英文文学名句，整体平面印刷质感。
> **适用**：krea2（Qwen3VL 自然语言长句，1000-1500 词级"设计 brief"最稳）。
> **主体锚定**：有官方角色串的角色 → 人物段**只写角色串 + 动作**，不补外貌词；原创 OC → 写精确可识别外观。
> 本文件属 `prompt-library/krea2/` 风格库（风格④）。参考成品：沙滩明信片（贴纸版）、古希腊旅行 vlog 海报卡片（平面版）。
> 来源：作者 2026-09-11 提出，2026-09-12 定稿。

## 一、提示词结构 / 要点

### 1. 两个版本（务必分清）
- **贴纸版（示例 A）**：元素带**白 die-cut 厚边 + 轻投影**，立体拼贴/贴纸感强，明信片味更浓。
- **平面版（示例 B，**作者偏好**）**：**去掉一切立体贴纸感**——无厚白边、无投影、无胶感、无 3D 浮雕，全部当"平面丝网/胶印图形"处理；改为**平面日系赛璐璐**。

### 2. 版式骨架（六块，位置与占比都写清）
1. **四边装饰边框**：细几何线、细规则、小三角/弧/点/菱形；四角纹样（太阳 / 橄榄枝 / 波浪螺旋 / 气泡）；上缘几何贴边条、下缘波浪扇贝线；边距散落小星点。
2. **左侧 1/3 · 旅行文字版块**（专治"左侧空荡"）：大字标题（目的地名，**引号包裹**）+ 副行 + 细装饰线；`TRAVEL DIARY`、`DAY 01`、经纬坐标、海域名；标签胶囊 `#SUMMER` `#ISLAND`；**虚线航线 + 岛屿地图片段 + 小飞机**；锯齿边**邮票**（内含当地建筑小图）；图例行、罗盘玫瑰；竖排菱形装饰线。
3. **中央偏右 · 大白框窗口**（主画面）：**平面设计框**（等宽干净边框 + 内外细线 + 角部小饰），**不是贴纸**；范围要**大**——左缘约在画面中线、右缘贴近右边框，上下跨中部区域。
4. **窗内 = 主体 + 旅行地（强绑定）**：人物服装、道具、背景**全部与目的地一致**。希腊示范：chiton 长袍 + 金绳腰带 + 金臂环 + 橄榄枝花冠 + 金凉鞋 + himation 披肩；大理石台 + 纸草卷 + 酒杯葡萄；蓝顶白屋 + 爱琴海 + 神庙柱 + 橄榄树 + 九重葛。
5. **贴纸 / 剪纸元素**：白 die-cut 贴纸（鲸鱼、花朵束、叶）；平面剪纸剪影（棕榈、帆船、海鸥、珊瑚、波浪云）。
6. **英文文学名句**：细衬线字排进边距，**必须引号包裹**（海洋/旅途主题佳）。

### 3. 上色与材质
- 平面日系赛璐璐：`clean lineart` + 平涂色块 + **硬边阴影**（2-3 级明暗），极少柔化渐变。
- 印刷质感：纸纹、网点 halftone、丝网/胶印感。
- 色彩预算：米白纸底 + 一个主色（海洋蓝/爱琴蓝）+ 少量点缀（珊瑚、沙金、橄榄绿）。

### 4. 文字策略（krea2 特性，最易踩）
- 要出现的英文**一律引号标注**：`a bold headline reading "SANTORINI"`、`the line "Roll on, thou deep and dark blue Ocean, roll!"`。
- 要么「引号 + 指定内容」，要么「声明完全禁止文字」——**绝不同图混用**。

### 5. 参数备忘
- 比例：16:9 常用（贴参考图比例）。
- 分辨率：初始 **1096×616**（≈0.67M 像素，8 的倍数）→ ×1.5 = **≈1.52M** → seedvr2 出 **2560×1442**。
- 画风 LoRA：`Krea2-2D动漫Anime_Flat_V20_nnegret:1.00`（2D 平涂，`--loras` 点名开启；默认三件套照旧保留）。

## 四、复用要点

| 换什么 | 改哪里 |
|---|---|
| 换目的地 | 标题字（引号内）、坐标、海域名、邮票内小图、标签胶囊，以及窗内**服装 + 道具 + 背景一整套**（希腊 ↔ 日本 ↔ 巴黎 ↔ 冰岛） |

| 换配色 | 改色板词，保持"米白纸底 + 一个主色 + 少量点缀"的预算结构 |
| 换文字 | 只换引号里的内容；名句按主题挑（海洋/旅途/远方） |
| 加减装饰 | 贴纸与剪纸剪影按目的地换（棕榈 ↔ 樱花 ↔ 梧桐） |
| 换比例 | 按参考图比例定；初始分辨率守 krea2 规则（≈0.6-0.7M 像素、8 的倍数、×1.5 后约 1.5M） |
| 左重右轻翻版 | 若要主体在左，则把文字版块整体镜像到右侧，白框窗口移左，其余规则不变 |
