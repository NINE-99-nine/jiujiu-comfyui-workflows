# 03 · 人设卡片（日系赛璐璐平涂角色设定卡）

> **风格定位**：日系高质量赛璐璐平涂（cel shading）角色人设卡片——米白纸底、**白色贴纸画框**、元素丰富绚烂、**线条主义 + 色块感**、八层拼贴叠加的角色设定集封面。
> **适用**：krea2 ｜ **主体锚定**：原创 OC 无官方触发词 → 人物段直接写其**精确可识别外观**；有官方角色串的角色则只写角色串 + 动作。
> 本文件属 `prompt-library/krea2/` 风格库（风格③）。参考图：海洋拼贴明信片（白色贴纸/窗口）+ 平面设计海报（白框小稿群 / 图纸线 / 钴蓝干刷色块）。
> 来源：作者 2026-09-07 提出，赛琳娜人设卡片定稿。

## 一、提示词结构 / 要点

**版式（横向宽幅，模拟角色设定集封面）**
- 底层：米白/象牙白粗糙纸面（污渍、水渍、折痕、纸纤维、网点噪点）。
- 左上：超大号极粗黑色无衬线标题字（引号标注准确内容）+ 竖排小字 + 伪手写批注/编号/签名（不要求语义）。
- 中央偏右：主体角色，四分之三侧身，**赛璐璐平涂**（硬边色块、2-3 级明暗、极少柔化）。
- 左侧：竖排 3-5 个**白色贴纸画框**（米白底 + 极细黑灰边、无投影），内嵌局部设定小稿（眼睛特写/手/服装细节/背影等），形成"资料卡"信息网格。
- 右侧：大块钴蓝干刷色块 + 粗重黑色墨柱（交叉成画外十字）。
- 外围：丰富**白色贴纸元素**（白边 + 轻浮雕/投影）——花/星/云/小鸟/气泡/几何徽章，大小错落。

**三套线条系统（线条主义，务必区分）**
1. **人物线**：细、软、有色（深蓝黑），断续、粗细有呼吸、不闭合，色块可溢出轮廓。
2. **图纸线**：均匀精确细黑线（同心圆靶心、十字准星、箭头、刻度、网格）。
3. **干刷线**：极粗、毛糙、飞白、浓淡不均（墨柱、蓝刷痕、飞溅墨点）。

**色块感**：赛璐璐硬边色块 + 钴蓝干刷大色块 + 米白留白 + 近黑墨柱；**红色点睛 <2%**。

**图层层次（自后向前，八层）**：纸底 → 蓝黑色块/撕纸 → 图纸线 → 白色贴纸画框群/色卡 → 小风景插图 → 人物（发梢与蓝刷痕交叠，人物压在背景上）→ 标题文字 → 墨点/颗粒噪点/暗角统一滤镜。

**色彩预算**：冰蓝/钴蓝/近黑深蓝/米白象牙为主；红色仅用于角色身上的语义点（红绳/眼眸/记号）。**严禁大面积高饱和与彩虹渐变。**

## 二、完整示例 · 赛琳娜角色人设卡片（可直接投喂）

> 原创 OC「赛琳娜」（雪白长发 + 侧辫红绳 + 猩红眼眸 + 冷白皮 + 贵族千金 + 白竖条纹夏衫/黑丝带蝴蝶结/黑白格子百褶裙/玛丽珍鞋/厚黑丝）——无官方触发词，故人物段写精确外观。分辨率建议横向宽幅（如 16:9 或 2:1）。

一张日系高质量角色人设卡片海报，宽幅横向构图，模拟一册角色设定集封面与设计工作室的拼贴工作台，风格为干净的日系赛璐璐平涂（cel shading）：硬边色块、2 到 3 级明暗分块、边缘清晰、极少柔化渐变，辅以轻微的厚涂笔刷点缀在脸颊与发梢的高光处。整体像一张被认真排版过的角色资料卡，元素丰富、画面绚烂，但排布理性、层次分明，而非杂乱堆砌。

在人物左侧竖排一列白色贴纸画框（约四到五个），每个都是米白纸底的矩形小框、外描极细的黑灰边，内部各嵌一张她的局部设定小稿：一格是她的背影与侧发辫、一格是她猩红眼眸的夸张大特写、一格是戴黑手套或白手套的手部速写、一格是领口蝴蝶结与荷叶边的服装细节、一格是黑白格子裙摆的褶皱特写。这些白框像平整贴上的设定贴纸，无投影或仅有极淡投影，与人物处于同一深浅平面，制造出"人物资料卡"的信息网格感。在框群之间错落贴上三四个无边的蓝色与米白色小方贴纸色卡，像材质样本。

在画面左上角放置一行超大号、极粗的黑色无衬线标题字，内容为准确的英文" SELINA "，字体紧密、理性、带有印刷感；标题下方缀一行更小的竖排等宽小字"design archives"，以及若干不可读的手写体批注、细数字编号与签名式花体，作为"手写批注"的视觉功能，不要求语义成句。让标题、批注与箭头共同构成一条从左上向右下延展的视觉动线。

以米白与象牙白的粗糙纸面为最底层，纸面遍布污渍、水渍、折痕、纸纤维与细密网点噪点，像一张反复使用过的档案卡纸。其上叠入平面设计的几何系统：多个以细黑线绘制的同心圆靶心（中心带蓝点）、十字准星、端点小十字的刻度线、放射状虚线与手绘感箭头、浅灰矩形网格，以及散布的小圆点与小方块坐标点，构成"工程蓝图"的理性秩序感。在画面右侧铺入大块钴蓝与宝蓝的干刷笔触色块，横向贯穿，配一根粗重的黑色墨柱与一根横黑条，交叉成画外的十字结构；左下与右上另留几块被撕下的白灰色几何纸片。

线条主义由三套并存的线条系统构成，请严格区分：其一是人物线——细、软、有色（深蓝黑），断续、粗细有呼吸，用在轮廓与五官；其二是图纸线——均匀、精确的细黑线，用于同心圆、准星、箭头、刻度与网格；其三是干刷线——极粗、边缘毛糙、带飞白与浓淡不均，用于右侧的墨柱、蓝刷痕与飞溅墨点。人物线不闭合，色块可溢出轮廓，让实拍与手绘交错；所有线条最终都被一层统一的噪点与颗粒覆盖，压住数字感。

## 三、复用要点

- **换角色**：替换主体外观段——原创 OC 写精确外观；有官方角色串的角色只写角色串 + 动作（禁补外貌词）。
- **换主色**：把钴蓝系整体替换为另一主色，保持"主色 + 米白留白 + 近黑墨柱 + <2% 点睛"的结构。
- **换贴纸题材**：外围白色贴纸元素换成新主题（花 / 星 / 机械 / 季节物 / ……）。
- **文字**：标题用引号标注可读内容，其余为伪手写批注（不要求语义）。
- **比例**：横向宽幅（16:9 或 2:1）；此风格依赖横向留白与左框右块的版式，勿用竖版。
