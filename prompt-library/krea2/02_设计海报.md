# 02 · 设计海报（实验性设计 / 概念游戏主视觉）

> **风格定位**：实验性设计海报 / 概念游戏主视觉——多重叠印、几何蒙版、档案取样窗口、色彩预算与明确焦点层级，平面设计感优先，**不是自然场景、也不是普通插画**。
> **适用**：krea2 ｜ **文字策略**：每张图二选一并贯彻到底——「带引号可读」或「完全禁止文字」。
> 本文件属 `prompt-library/krea2/` 风格库（风格②）。

## 一、提示词结构 · 十段骨架（复用模板）

按顺序成段书写，每段一个职能。设计海报/概念图/主视觉类任务直接套用。

1. **开场定调**（1-2 句）：给整图定性——"这是哪种东西"（实验海报/概念主视觉/编辑设计），并**反向框死**别跑偏：`The result should feel intentionally chaotic... rather than randomly cluttered` / `not a natural scene and not a conventional illustration`。
2. **角色锚定**：四件套——**唯一角色** + **保识别度不改造型** + **禁加无关特征** + **脸部/眼神/表情=绝对保护区**（外围发梢/服装/下半身允许被设计层分割覆盖，但绝不动脸）。
3. **分区构图**：每个设计元素写清 **位置 + 占比量化 + 相对关系**，并给**焦点层级**（第 1/2/3 焦点）。
4. **色彩系统 = 分配预算**：主色归主体、点缀色只给指定小元件、明确禁色。
5. **材质质感**：质感词库堆叠（粗糙哑光纸/旧档案封套/纸纤维/油墨吸收/干刷/复印噪点/套印误差）+ **反质感排除**（不做光滑 CG/精致摄影/3D 渲染/奇幻光效/过量粒子）。
6. **层次遮挡**（krea2 最吃这口）：让东西与背景**真正融合、不是干净的抠图图层**——穿插、半透明叠印、正反相蒙版、**遮罩"边缘锐利但内影柔软"**、同时**留干净区**（脸周不穿线）。
7. **细节充实**：小型标识/刻度/元素堆叠（空心圆、十字定位符、取样框、扫描线、撕裂边），保证耐细看。
8. **负面排除**：尤其"**完全禁止文字/字母/数字/水印/二维码**"、"避免过度光效/杂乱/密度失衡"。
9. **情感概念句**：给一句"它想表达什么"（`在显现与消失之间建立强烈张力` / `困在记忆层中的声音`），帮模型抓情绪温度。
10. **结尾风格标签连排**：comma list 钉一组风格坐标收口（Swiss grid / glitch / brutalist / Y2K cyber / 现代游戏主视觉…）。

> 词量规则（**无硬限，可长可细**）与写作总纲见 `workflows/krea2/prompting.md`。

## 案例 1 · 《THE WALL》砖墙概念海报（中文叙事，带英文标题文字）

**【类型】** 概念性游戏海报 / 艺术摇滚拼贴 ｜ **【比例】** 概念海报 ｜ **【文字策略】** 带英文标题文字，须准确可读 ｜ **【核心手法】** 半透明肖像重复叠印 × 砖缝横穿人物脸部（穿插式遮挡）× 红色湿润手写 + 正反相蒙版 ｜ **【复用要点】** "砖墙阻隔精神"的经典范式——角色被墙体/照片/手写宣言重构，红黑白灰克制配色。

```
一张概念性游戏海报, 角色使用初音未来, 并以所附参考图中的音乐专辑拼贴感、白色砖墙网格、重复半透明肖像叠印、粗糙红色手写字体、情绪碎片化与反叛艺术摇滚氛围作为主要视觉依据.初音未来是画面中唯一具有明确身份的虚构角色, 保留她的经典角色识别度, 不要加入无关身体特征, 不要将她改造成其他人物, 也不要引入真实音乐人或真人照片.整体海报围绕名望、记忆、封闭、舞台身份以及表演者和观众之间的墙展开.,

让整张画布被浅白色与冷灰色砖墙覆盖.砖墙由不规则横向砖层组成, 每块砖之间使用细窄的深蓝灰色砂浆线分隔.砖块纹理必须延伸到整张画面, 包括人物肖像前方, 使墙体成为半透明的阻隔层, 而不是普通背景.略微改变砖块宽度, 加入手绘般不均匀的边缘、浅淡污渍、掉漆区域、细小裂缝、脏旧角落、轻微阴影以及白色涂层变薄后的半透明效果.保留砖墙明显的横向节奏, 同时让少数砖块轻微错位, 制造压迫与不稳定感.,

在画面中央偏左的背景中放置一幅大型初音未来正面半透明肖像, 占据约一半画面高度.该肖像应当褪色、幽灵般、被砖墙部分隐藏, 脸部与上半身透过低透明度白色叠层显现.在画面右侧放置第二幅更大的初音未来肖像, 占据右侧三分之一区域, 使其更加清晰、深暗, 并带有疏离感.让右侧肖像通过透明交叠与中央肖像发生融合, 如同多张照片或不同记忆画面被重复印刷在一起.在下方中央或左下方加入第三幅被裁切的初音未来肖像, 头部略微向下倾斜, 表现更加私密、脆弱的情绪.所有重复肖像都必须明确属于初音未来, 但在尺寸、透明度、角度和情绪温度上形成区别.,

让人物肖像与砖墙真正融合, 而不是作为干净的抠图图层放置.允许多条砖缝横向穿过人物的脸部、脖颈、肩膀、双手与服装, 形成半透明的视觉中断.砖墙线条应当覆盖人物, 但不能完全破坏面部识别.使用不同的透明度：中央肖像可以非常浅, 接近被白色洗掉；右侧肖像可以拥有更强的深蓝灰对比；下方肖像则逐渐溶解为白色、黑色与低饱和蓝色的摄影碎片.加入轻微双重曝光、错位脸部轮廓、重叠眼睛位置、重复肩部剪影和透明建筑块, 制造角色仿佛被困在多重心理屏障与视觉墙体之后的感觉.,

使用受限制的色彩方案, 包括暖白色、冷象牙白、浅灰色、灰尘蓝、深海军蓝、炭黑、低饱和米色与强烈暗绯红.砖墙整体保持白色与冷灰色.使用深蓝和炭黑表现最强的人物阴影、砖缝轮廓、深色背景碎片和下方图像模块.暗红色仅用于主手写标题、小型颜料笔触、破损下划线、箭头和局部红色反光.红色应当像湿润刷子或粗马克笔直接涂在墙面上, 具有不均匀透明度、拖拽痕迹、偶然飞溅和轻微渗入纸面的边缘.避免使用霓虹色, 也不要采用光滑商业化调色.,

在画面上方中央与中央偏左区域放置大型红色手写标题, 使用准确可读的文字"PINK FLOYD".在其下方继续放置第二行红色手写标题"THE WALL".字体应当粗粝、手工、细长、充满不稳定感, 笔画粗细不断变化, 边缘破碎, 带有颜料滴落、与砖缝交叠的痕迹, 以及少量超出基线的拉长笔画.标题必须清晰可辨, 但有意保持不完美.围绕标题加入细红色箭头、斜向划痕、下划线与未完成的记号, 仿佛有人直接在墙上写下这些文字.红色标题应成为主要平面设计元素, 但不能完全覆盖初音未来的核心脸部.,

将"墙体专辑"概念转化为虚构的初音未来音乐海报, 不要复制任何现实专辑封面、真人演出照片或商业品牌.于左下方或中央下方加入准确可读的文字"初音未来", 并搭配窄体英文文字"HATSUNE MIKU".加入少量辅助短句, 例如"THE VOICE BEHIND THE WALL""LIVE MEMORY / SIGNAL ARCHIVE""SIDE A — SIDE B"和"NO EXIT FROM THE ECHO".这些文字应融入砖墙结构, 部分内容可以被砂浆线打断.排版保持稀疏、手工和拼贴感, 不要变成整洁的数字界面.,

建立明确的多层叠印关系.最前景是覆盖整幅画面的砖墙网格；浅淡的中央肖像位于墙后；深色右侧肖像存在于两层砖石结构之间；下方若干摄影碎片则部分隐藏在黑色或深蓝色矩形块后面.在右下方加入一块宽大的深色半透明矩形, 内部包含被裁切的肖像细节、微小档案笔记和几乎不可见的时间戳式标记.在左下方肖像周围加入浅白色撕裂矩形与不规则负空间块, 使其像撕下的照片、被审查的记忆、联络表碎片或损坏的印刷层.,

加入受到拼贴艺术与抗议海报启发的视觉干扰：细横向扫描线、错位砖层、透明灰色矩形、撕纸边缘、反向摄影碎片、孤立眼睛形状、被裁切的手部、斜向构造标记、红色颜料刮痕、褪色编号以及围绕局部面部细节绘制的手写圆圈.部分元素可以跨过人物外侧肩膀或服装, 但眼睛、嘴部与主要脸部结构必须保持可读.在指定区域使用逆向色彩蒙版, 将浅色肖像转化为深海军蓝剪影, 也将深色服装区域转化为褪色象牙白镂空.所有蒙版都应具有模拟印刷、手工拼贴和不规则边缘感, 避免过于工整的几何效果.,

使用带有轻微冷色调的柔和正面日光, 仿佛有人正在拍摄一张贴在墙上的实体拼贴作品.加入砖缝之间的柔和阴影、涂漆表面的浅反光、纸张颗粒、油墨吸收、干刷纹理、复印机噪点和低透明度摄影褪色.墙面与人物照片应当处于同一个真实物质空间中, 具有可触摸的纸张与印刷质感.避免电影式奇幻光效、魔法特效、过量粒子、干净的三维渲染、精致时尚摄影和光滑数字专辑界面.,

最终构图应传达一种被封闭的表演者、一种困在记忆层中的声音, 以及被墙体、照片和手写宣言不断重构的公众形象.实验音乐海报, 艺术摇滚拼贴, 白色砖墙阻隔, 半透明角色肖像, 红色抗议式手写字体, 心理视觉碎片, 档案印刷纹理, 磨损混合媒介, 层叠负空间, 粗粝手绘排版, 现代游戏宣传主视觉, 克制却带有反叛力量的情绪氛围, 在显现与消失之间建立强烈张力.,
```

## 案例 2 · 黑色档案 X 光花 · 竖 3:4 实验性游戏角色海报（完全无文字）

**【类型】** 实验性游戏角色海报（黑色档案/透明标本）｜ **【比例】** 竖 3:4 ｜ **【文字策略】** **完全禁止任何可读信息** ｜ **【核心手法】** 局部彩色取样窗口 + 数据节点网络 + 分层蒙版锐边软影 + 三重焦点（人物/花/蝶）｜ **【复用要点】** "无文字 + 医用 X 光 + 档案分析"的克制氛围；彩色只存在于取样窗口，其余近黑白。

```
制作一张竖向3:4比例的现代实验性游戏角色海报，角色使用Hatsune Miku，并参考所给画面的黑色纸张背景、半透明X光花卉、局部彩色取样窗口、白色节点连线、空心方框和档案分析式平面构成。保留Hatsune Miku具有辨识度的经典角色身份、原有角色轮廓与既定服装逻辑，不擅自增加无关种族特征，不随意修改角色造型。将Hatsune Miku安排在画面中央略微偏右的位置，占据中部至右下方约二分之一的空间，人物采用安静直立或轻微悬浮的姿态，身体向左转动少许，头部回望观众，一只手轻触胸前盛开的花朵，另一只手自然垂下并靠近透明花瓣边缘。保持脸部、眼睛、双手与主要人物轮廓清晰可辨，外围装饰可以覆盖发梢、袖口和下半身，但不得遮挡核心表情。

使用深黑、炭灰与轻微暖黑作为整个画布的基础色，使背景呈现粗糙哑光纸张、旧档案封套和深色粉笔板混合的触感。加入细密纸纤维、极轻微折痕、印刷颗粒、擦拭痕迹、灰尘和低对比度划痕，但不要出现任何文字、字母、数字、代码、文件名、标题、说明标签、标志、水印或签名。画面左上方、左侧中部和四周边缘保留较大面积黑色负空间，只让少量白色细线和透明薄翼穿过，使整体保持克制、神秘与具有呼吸感。

将Hatsune Miku的主体处理为真实角色插画与半透明医学影像质感的结合。脸部和双手保持自然清晰，使用柔和冷白光、浅灰阴影和少量粉蓝反射表现；人物外层服装、头发末端和下半身则逐渐转化为透明银蓝色结构，显露出类似叶脉、花瓣纤维、薄膜褶皱与声音波形的内部纹理。不要表现真实骨骼或惊悚器官，而是用抽象的植物脉络和声波线路替代内部结构，使角色仿佛由花朵、透明薄膜和数据网络共同构成。让部分头发与巨型花瓣自然融合，但必须保持人物身份清楚。

在人物身后与右下方放置一朵巨大的半透明花朵，花朵直径约占画面宽度的一半，使用冷白、银灰与淡蓝色X光效果表现。花瓣层层展开，外缘柔软发亮，内部可见细密叶脉、纤维和半透明重叠阴影。花朵中心嵌入一块不规则的柔粉色彩色区域，像从黑白影像中被单独保留下来的真实色彩样本；该粉色区域由半透明方形蒙版限制边界，但蒙版不带任何标签。让花朵与Hatsune Miku的胸口、肩部和发梢产生视觉连接，仿佛歌声正从角色体内生长为透明花瓣。

在画面左上方加入一只大型半透明蝴蝶或由两片薄翼组成的抽象飞行结构，使用冰蓝、银白与极淡虹彩表现。翅膀内部具有清晰而优雅的脉络，边缘带有轻微折射与纸张般的褶皱。蝴蝶的一部分被一个空心方框裁切，框内保留少量柔粉、浅青、淡黄和珠光蓝的局部彩色纹理，框外则恢复为冷白透明影像。让蝴蝶朝向Hatsune Miku和中央花朵飞行，通过一条纤细弧线与人物手部产生视觉联系，象征即将消散的记忆与仍在移动的声音。

在整个画面上建立一套没有文字的数据节点网络。使用极细的暖白色直线连接人物、花朵、蝴蝶、发梢、手指和画面边缘，形成不完全对称的多边形网格。线段应当具有明确的交点与方向变化，每个关键交点使用小型空心圆、白色圆点、短线刻度或微小十字定位符表示。加入若干不同尺寸的空心矩形、半透明深绿色小方块、灰紫色取样框和浅青色玻璃框，使其像在分析画面中的不同材质，但所有框内外都不能出现文字和数字。部分连线可从画面边缘延伸出去，制造仍在持续运算和生长的感觉。

使用分层蒙版控制角色、花卉与数据图形的关系。在Hatsune Miku脸部周围保持一块干净清晰的透明区域，不让连线穿过双眼和嘴部；在肩部、外层头发、袖口和下半身加入数块半透明矩形蒙版，使局部颜色从自然状态反转为银蓝色、灰紫色或苍白的X光剪影。让一个柔粉取样框覆盖人物胸前花朵与部分手指，但保持手部结构清楚。再让一个低饱和青绿色小方块覆盖右侧花瓣边缘，内部花瓣呈现更清晰的纤维纹理。所有蒙版边缘保持锐利，内部影像则柔软、透明且具有轻微错位。
```
