# krea2 · 优质提示词风格库

> krea2（Qwen3VL CLIP，自然语言长句）专属的**可复刻成品提示词范式库**：存放"写好的高质量提示词长什么样、怎么照着复刻"，供日后直接取用与二次创作。
>
> **与工作流侧分工（勿混）**：`workflows/krea2/prompting.md` 管「**书写格式规范**」、`guide.md` 管「**工作流使用指南**」；本目录管「**成品范式 + 复刻资料**」。

## 一、分类机制（新风格一律按此归置，禁止乱放）

1. **一个风格 = 一份 `.md` 文档**，文件名统一 `NN_风格名.md`（两位序号前缀 + 中文风格名，如 `01_巨构指导学.md`）。
2. 新增风格：**追加下一个空序号**，并把它补进下方「风格索引」表——**索引与文件必须同步**。
3. 每份风格文档**必须**含以下四段（顺序固定），保证一律按同一结构复刻：
   - **① 风格定位**：一句话说清是什么风格、适用什么画面、注意什么。
   - **② 提示词结构/要点**：这套风格怎么写（镜头/构图/材质/线条/色块/文字策略等）。
   - **③ 完整示例**：可直接投喂 krea2 的原文（中文或英文），标注比例与文字策略。
   - **④ 复用要点**：换主体/换色/换场景时改哪里。
4. **本目录不放**：书写格式规范（→ `workflows/krea2/prompting.md`）、工作流节点与提交方式（→ `workflows/krea2/guide.md`）、跨模型通用词条。

## 三、成果图归档（`samples/`）

> 目的：看风格案例时能**直接对照该风格的实际出图效果**，一一对应、无需另找文件。

1. **一个风格一份成果图**；同一风格多次出图时全部保留，靠文件名区分（命名：`NN_风格名[_版本]_主体_日期.png`）。
2. **新增出图后三件事（缺一不可）**：
   - ① 图放入本目录 `samples/`；
   - ② 在**对应风格文档顶部**挂一行图片链接，并注明出图参数（原文出处／初始分辨率／最终尺寸／LoRA／日期）；
   - ③ 更新上方「风格索引」表的**成果图**列。
3. 成果图是**实出成品的证据**，不参与提示词正文；替换或删除前先与作者确认。

## 四、维护约定

- 新增/修改风格文档后，**同步更新本索引**。
- 正文用中文（提示词原文可中英双语）；文件行尾统一。
- 每份风格文档末尾记一句**来源/定稿时间**。
