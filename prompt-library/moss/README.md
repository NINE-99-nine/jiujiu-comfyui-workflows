# moss · MOSS-Image 提示词库

MOSS-Image 的成品提示词存档。它吃**自然语言长 caption**，也吃 **Scene JSON / Layout JSON**（带 bbox 定位框），后者是它能画多人、能精确排版的真正原因。

## 收录规矩

- **只收成品提示词与复刻要点**，不收官方案例目录、不收别人的案例清单。
- 一份文档 = 一个可复用的写法，命名 `NN_写法名.md`。
- 提示词原文逐字照抄，不缩写；结构说明只讲「这套东西凭什么成立」。
- 官方参数与本机实际档位不同时，两栏并列写清。
