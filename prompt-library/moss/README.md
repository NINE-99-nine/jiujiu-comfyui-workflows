# moss · MOSS-Image 提示词库

MOSS-Image 的成品提示词存档。它吃**自然语言长 caption**，也吃 **Scene JSON / Layout JSON**（带 bbox 定位框），后者是它能画多人、能精确排版的真正原因。

## 风格索引

## 样图

`samples/01_多人图_官方十人BA群像_复刻_2026-10-20.webp` —— 用官方 Scene JSON 原文 + 官方 seed `3072627948` 在本机 **8 步旧档**（现默认 8 步 / cfg 1.0）复刻的成图（1776×1184）。十人全部独立可辨，可作为「bbox 布局到底解决了什么」的直观参照。

`samples/03_漫画分镜设计_夜查黑料_2026-10-28.webp` —— 一页七格漫画（1152×1728）：6 个对白框的文字由 `text` 字段直出，位置由 bbox 锁定。

## 收录规矩

- **只收成品提示词与复刻要点**，不收官方案例目录、不收别人的案例清单。
- 一份文档 = 一个可复用的写法，命名 `NN_写法名.md`。
- 提示词原文逐字照抄，不缩写；结构说明只讲「这套东西凭什么成立」。
- 官方参数与本机实际档位不同时，两栏并列写清。
