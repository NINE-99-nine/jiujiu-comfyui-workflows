# prompt-library · 通用提示词词汇库

> 本目录存放**工作流无关**的通用提示词词汇库，供 jiujiu-comfyui-workflows
> 伞技能下所有工作流（anima 及日后的新工作流）复用。
> 与 execution/（执行）、html-embedding/（嵌字）平级，属于通用资产层。

## 内置词库（当前）

| 词库 | 内容 | 规模 |
|------|------|------|
| `nsfw/` | 色情提示词（场景/动作/服饰/氛围/镜头/光色/触发词，负面已剔除） | ~370 词条 |

## 扩展方式

新词库在 `prompt-library/` 下新建平行子目录，命名与内部结构保持一致：

```
prompt-library/
├── README.md          # 本文件
├── nsfw/              # 色情词库（唯一内置）
│   ├── 01_场景与动作.md
│   ├── 02_服饰与氛围.md
│   ├── 03_镜头体系.md
│   ├── 04_光色与风格.md
│   ├── 05_触发词库.md
│   └── 06_使用示例.md
├── sfw/               # （示例）清水词库
├── landscape/         # （示例）风景环境词库
├── style/             # （示例）画风词库
└── scripts/           # 词库提取/维护脚本
```

## 新增约定

1. 每个词库目录自带 README 或 00_总览（来源、用途、更新方式）
2. 中文分类文件名（01_xxx.md 序号前缀），英文内容正文（直接可粘贴进提示词）
3. 负面提示词一律不入库（内嵌工作流，不交付）
4. 源码更新 → 跑 `scripts/extract_prompts.py` 重提取
